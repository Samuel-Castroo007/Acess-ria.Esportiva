Falta configurar o repositório

Abra o arquivo horarios-data.js e troque GITHUB_OWNER e GITHUB_REPO pelo seu usuário e pelo nome do repositório no GitHub. Depois publique de novo e recarregue esta página.

Área restrita

Cole seu token do GitHub para gerenciar os horários.

Ainda não tem um token? Crie um token de acesso pessoal (fine-grained):
  1. Em "Repository access", selecione só o repositório deste site.
  2. Em "Permissions → Contents", escolha Read and write.
  3. Gere o token e cole aqui. Guarde-o em local seguro — ele não aparece de novo no GitHub.

Gerenciar horários

Toque em um horário para alternar entre Livre e Ocupado. A alteração é salva no GitHub na hora.

Os horários de Instrução (turma fechada) aparecem só como informação — não têm status para alternar.
As mudanças feitas aqui aparecem no site para qualquer pessoa, em qualquer aparelho, assim que a página é atualizada.
